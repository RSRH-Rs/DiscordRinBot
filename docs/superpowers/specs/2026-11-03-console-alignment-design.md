# 控制台改版四：对齐与细节打磨

日期：2026-11-03
前一版：`2026-11-03-console-flat-layout-design.md`（平铺列表排版，已上线，d90a906）

## 1. 目标

用户的反馈是：有些地方排版不对称，比如抽奖表单里两个下拉框上下错位。要用对齐和对称的方法打磨细节，参考 Apple、Microsoft、Google 的做法。

这一版要做到：

- 并排的东西顶边对齐，靠右的控件右边贴同一条线。
- 同类控件一样高、一样宽，文字对齐方式一致。
- 层级关系一眼能看出来：子设置看得出属于哪个开关。
- 间距、圆角、字重各只用一组固定数值。

成功标准：
- 对齐检查脚本（第 8 节）在概览、11 个模块页的每个标签页、服务器列表、全局设置上零报错，1440、1080、375 三种宽度和日间、夜间两套配色都检查。
- 用户在本地试用版里逐页看过，同意部署。

## 2. 现在的问题（2026-11-03 在 1440×900 和 375×812 下实测）

1. **抽奖表单错位。** "参加限制"的标题下多一行说明，它的下拉框比左边"发到哪个频道"低 27px（顶边 309 对 282）。整个控制台只有这一处用了两列网格（`.form-grid`）。
2. **数字框文字居中。** 共 10 个：自动审核 `am-st`、`am-si`、`am-ct`、`am-rt`，管理 `mod-mt`、`mod-kt`、`mod-bt`，抽奖 `gw-winners`，以及自动审核和管理页分段选"自定义"后才出现的两个时长数字框。其他输入框都靠左。
3. **单位在框外。** "%"、"次"、"次警告"、"条 /"、"秒"宽度不同，数字框的右边对不齐。"触发条件"的说明写"几秒内发几条消息算刷屏"，控件却是"[5] 条 / [5] 秒"，顺序反了。
4. **控件高度有 5 种。** 输入框和自定义下拉 40px，原生下拉 39px，分段选择 38px，按钮 35、36、40px 都有。管理页"自定义时长"的数字框和单位下拉并排，差 1px。
5. **分段选择按文字宽度分段。** 各段宽度不同，选中项加粗后会变宽，`flex-wrap: wrap` 让它在窄屏上可能折成两行。
6. **子设置没有缩进。** 自动审核里 6 行子设置和它们的上级开关排在同一级，只靠变灰提示：触发条件、禁言多久（属于反刷屏），大写比例阈值（属于大写轰炸过滤），连续次数（属于重复消息过滤），违禁词列表（属于违禁词过滤），白名单域名（属于链接过滤）。
7. **编辑页的总开关不在开关线上。** 欢迎新成员页的页头横跨表单和预览两栏，"开启"开关在 1032px 的右边，表单里的开关在 680px 的右边。
8. **原生上传控件。** 欢迎页"自定义大图"和"道别自定义大图"直接露出浏览器的"Choose File / No file chosen"，英文、没有样式。全局设置的头像已经用了自定义按钮。
9. **处罚记录显示英文。** 标签是"#1 warn""#2 mute"，直接显示了数据库里的动作名。
10. **间距和圆角太杂。** 样式表的内外边距和间隙用了 23 种数值，其中 3、7、10、14、18、22、26、28、30、34、36、50px 不在 4px 网格上（10px 用了 47 次，14px 用了 19 次）。圆角有 10 种：3、4、5、6、7、8、9、10、12px，加上 999px 和 50%。
11. **字重 500 在 Windows 上不存在。** 设置行标题用的 500，微软雅黑只有常规和粗体，Windows 上显示成常规，和下面的说明一样细。
12. **手机开关太小。** 开关 40×22，点按区就是这么大；概览里它紧挨着整行可点的链接，点偏一点就进了模块页。

## 3. 范围

**要改：**
- 控制台所有页面：概览、11 个模块页、服务器列表、全局设置，以及侧栏、保存条、Ctrl K 搜索框这些外壳部分。
- 主页 `templates/index.html` 只改第 6 节里的两处：手机浏览器地址栏颜色和金色排名字。

**保持不变：**
- 后端接口、保存逻辑、草稿和保存条的行为，以及概览快速开关立即生效、模块页总开关要点保存这套规则（统一保存规则另做，见第 7 节）。
- 配色 token 的取值和五档字号（12、13、14、16、22px）。
- 表单控件的元素 id。各模块脚本只在必须时改。
- 平铺列表的整体结构、680px 内容栏、编辑页 320px 预览栏、标签页深链、Ctrl K、服务器切换器、外观切换。
- Discord 消息预览（`.preview`）和登录页背景示意（`.fake`）照抄 Discord 的尺寸，不受第 4 节的数值限制。
- 不引入构建工具和框架，文案仍然放在 `website/i18n/zh.json`。

## 4. 全站规则

### 4.1 两条竖线

- **左边线**：所有内容从内容栏左边开始（上一版已做到，这次不能破坏）。
- **控件线**：所有放在行右侧的控件（开关、下拉、数字框、按钮）右边贴内容栏的右边，也就是 680px 栏的右边。
- **编辑页**（欢迎新成员、领取身份组）改成两栏从页面顶部开始：左栏依次是页头（标题、介绍、总开关）、标签、表单，最宽 680px；右栏是 320px 的预览，顶边和页头标题的顶边对齐，仍然吸顶。这样总开关落在 680px 栏的右边，和表单里的开关在同一条线上。视口小于 1200px 时改成一栏：页头、标签、表单、预览依次排列。

### 4.2 控件高度

- 新增 token `--control-h`：电脑上 40px；视口小于 860px 时 44px。
- 用它的控件：`.input`、`.select`（包括原生下拉，要写明 `height`）、`.select-trigger`、`.search-select`、数字框、`.seg`、`.btn`（`.btn--text` 和 `.btn--icon` 除外）。
- 多行文本框（`.textarea`）不受限制，只要求最小高度不小于 `--control-h`。
- 视口小于 860px 时，侧栏项、`.btn--icon`、菜单按钮的点按区至少 44×44。外观切换的三个按钮并排挨着，各自 44×36，用透明扩展区把点按高度补到 44。

### 4.3 开关

- 电脑上开关外观 40×22 不变，点按区扩到 40px 高，宽度不变。
- 视口小于 860px 时开关外观 48×28，圆点 24px，点按区 44×44。
- 设置行里，开关行的标题仍然是 `<label for>`，点标题也能切换。

### 4.4 数字和单位

- 所有输入框、下拉、文本框的文字一律靠左。
- **带单位的数字框**改成一个整体：外框里左边是数字，右边是单位，单位 14px、`--muted`（参考 Material 的 suffix 和 Fluent 的 contentAfter）。外框统一 120px 宽、`--control-h` 高，边框、底色、聚焦样式和 `.input` 一样，点单位也能聚焦数字。
- 隐藏浏览器原生的数字上下箭头。键盘上下键照样能调，手机弹数字键盘。
- 各数字框的单位：

| 数字框 | 单位 |
|---|---|
| `am-si` | 秒 |
| `am-st` | 条 |
| `am-ct` | % |
| `am-rt` | 次 |
| `mod-mt`、`mod-kt`、`mod-bt` | 次警告 |
| `gw-winners` | 人（新加文案 `giveaway.winners_unit`） |

- **"触发条件"改成句子顺序**：[5 秒] 内发 [5 条]。先是 `am-si`，再是连接词"内发"（新加文案 `automod.within`），最后是 `am-st`，和说明"几秒内发几条消息算刷屏"的顺序一致。删掉文案 `automod.messages_per`（"条 /"）。行标题"触发条件"的 `for` 指向 `am-si`，`am-st` 用 `aria-label` 写"消息条数"。
- **自定义时长**（自动审核和管理页的分段选"自定义"后出现）：120px 的数字框（不带单位）加 96px 的单位下拉，两个都是 `--control-h` 高，间隔 8px。

### 4.5 分段选择

- 每段等宽：宽度取所有段里最宽的那段（按选中时的粗体计算），最小 72px，所以切换选中不会让控件变宽。
- 不折行。
- 视口小于 860px 时分段撑满整行，各段平分宽度。
- 选中样式不变（`--accent-soft` 底、`--accent-text` 字、600）。

### 4.6 子设置

- **子设置行**：依赖同一列表里某一行开关的设置行。它整行往里缩 16px，上面那条分隔线也从缩进处开始画（iOS 设置的做法）。上级开关关着时子设置照旧变灰，不隐藏，让人看得到打开后能调什么。
- 依赖页面总开关的行（`w-enabled`、`am-enabled`、`bl-enabled`、`sl-enabled`）不算子设置，不缩进。总开关关着时页面已经有一行提示。
- 这次涉及的就是第 2 节第 6 条列的 6 行。模板里用 `row()` 宏的新参数明确标出，不靠选择器猜。

### 4.7 间距

- 内边距、外边距、间隙（`padding*`、`margin*`、`gap`、`row-gap`、`column-gap`）只用 0、4、8、12、16、24、32、40、48px 和它们的负值，另外允许 1px 和 -1px（让边框重叠或对齐细线）。
- 控件内部另外允许 2px 和 6px。"控件内部"指选择器以下面这些类开头的规则：`.btn`、`.input`、`.select`、`.search-select`、`.textarea`、`.num`、`.seg`、`.chip`、`.tog`、`.theme-switch`、`.nav-item`、`.tab`、`.palette-input`。
- 例外：内容区底部给保存条让位的 140px（含 `env(safe-area-inset-bottom)` 的写法），以及第 3 节说的 `.preview` 和 `.fake`。
- 设置行上下内边距从 14px 改成 12px。其余不在网格上的数值就近改到网格上，改完逐页截图对照，看不出差别或更整齐才算对。

### 4.8 圆角

- 只用四档：4px（小标签、徽章、色块小标记）、8px（控件、按钮、侧栏项、提示条、分段、服务器图标）、12px（弹出层、Ctrl K 面板、表情选择器、预览框、骨架屏、数字小方块）、999px（胶囊形和开关轨道）；圆形头像和圆点用 50%；贴边的整条元素（如手机上的保存条）用 0。
- **同心圆角**：一个元素嵌在另一个有圆角的容器里、四周留有内边距时，内圆角等于外圆角减去内边距（Apple 的做法）。目前只有外观切换一处：外框 8px、内边距 2px，里面三个按钮 6px。这是唯一允许的 6px。
- `--radius` 从 12px 不变，仍然给 12px 那一档用。

### 4.9 字重

- 只用 400 和 600 两档。
- 600 用在：页面标题、概览大标题、分组标题、选中的标签、选中的分段、按钮（`.btn--text` 除外）、侧栏当前项、服务器切换器里的服务器名、徽章文字。
- 其余都是 400，包括设置行标题（从 500 改）和概览模块名（从 600 改）。层级靠字号和颜色区分：行标题 14px `--text`，说明 13px `--muted`。参考 Windows 11 设置、macOS 系统设置、Material 列表的行标题，都是常规粗细。

## 5. 单页修改

### 5.1 抽奖：两列网格改成平铺行

"新建抽奖"分组改成和其他页一样的设置行，自上而下：

1. **奖品**：标题下面是撑满一栏的输入框（整行放控件的设置行），占位文字不变。
2. **中奖人数**：右侧是带单位"人"的数字框。
3. **发到哪个频道**：右侧是频道下拉。
4. **参加限制**：标题下是说明"不选就是所有人都能参加"，右侧是身份组下拉。
5. **什么时候开奖**：标题下是等宽分段，选"自定义"后在下面出现日期时间输入框，宽 240px。

分组下面仍然是"建立抽奖"按钮，靠左。删掉不再使用的 `.form-grid` 和 `.field` 样式。

### 5.2 欢迎页的图片选择

照全局设置头像的做法：原生文件输入框改成 `sr-only`，前面放一个 `<label for>` 做成的浅色按钮"选一张图片"（新加文案 `welcome.image.pick`）。按钮后依次是"上传图片""清除"和状态文字。状态文字在选了文件后显示文件名，没选时显示原来的"还没上传"。欢迎大图和道别大图都用这个宏，所以两处一起改。

### 5.3 处罚记录的类型

标签改成"#编号 类型中文名"。新加文案 `moderation.action.*`：

| mute | 禁言 |
| unmute | 解除禁言 |
| kick | 踢出 |
| ban | 封禁 |

标签的颜色类仍然用英文动作名。

## 6. 顺带修的七个小问题

这些是上一版复查后延后的小问题，都属于细节，这次一起修：

1. **空列表的细线。** 现在空的排行榜、处罚记录、抽奖记录不画上下细线，空的指令列表却画。统一为：列表容器（`.list`、`.case-list`、`.lb-list`、`.item-list`、`.cmd-grid`）里只有空状态（`.empty`）时，不画上下细线。
2. **回主页那一行的读屏名称。** 去掉 `aria-label`，让读屏名称取可见文字"小凛 RinBot 主页"（WCAG 2.5.3：名称要包含看得见的文字）。头像图片 `alt=""`。不再使用的文案 `nav.homepage_label` 删掉。
3. **手机抽屉的焦点。** 打开侧栏抽屉时，焦点落在服务器切换器上，不再落在回主页那一行。
4. **按住修饰键点击不拦截。** 有未保存修改时，按住 Ctrl、Cmd 或 Shift 点回主页那一行或切换器里的服务器，会在新标签页或新窗口打开，原页面的草稿不受影响，所以不弹离开提示、不阻止。中键点击浏览器本来就不发 `click` 事件，现在也不拦截，保持不变。
5. **主页地址栏颜色。** 主页开头读取外观设置的脚本，在用户手动选了日间或夜间时，把 `theme-color` 改成对应颜色（日间 `#F7F7F8`，夜间 `#17171B`）。跟随系统时保持现在的两个 `media` 版本。
6. **主页金色排名字。** 主页 Discord 示意图里排行第一名的金色，日间、夜间各定一个 token，对它所在的底色都达到 4.5:1，并加进主页的对比度测试。
7. **表情按钮底色。** 领取身份组里的表情按钮（`.emoji-trigger`）底色从 `--panel` 改成 `--field`，和其他控件一致。

| 编号 | 检查什么 |
|---|---|
| A | 同一行并排的控件顶边或高度不同 |
| B | 输入框、下拉、文本框文字不是靠左 |
| C | 同一页上输入框、下拉、数字框、分段、按钮（除 `.btn--text`、`.btn--icon`）高度不等于 `--control-h` |
| D | 同一组控件（行右侧、按钮行、自定义时长）中心线不在一条线上 |

| S | 分段各段宽度不等，或分段折了行 |
