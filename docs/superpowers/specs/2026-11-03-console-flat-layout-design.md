# 控制台改版三：平铺列表排版 + 主页统一

日期：2026-11-03
前一版：`2026-11-03-console-workbench-design.md`（工作台布局 + 瓷白樱粉 / 夜幕配色，已上线）
试装实例：`docs/superpowers/specs/assets/2026-11-03-console-flat-layout-demo.html`。示例是假数据，可以切换 A/B/C 三个方向，用户选了 A。图片路径来自对比页服务，单独打开时不显示。

## 1. 目标

用户的反馈是：控制台各页面"看起来太杂乱"，主页导航栏的配色和控制台对不上，控制台也回不到主页。

这一版要做到：

- 每一页都用同一副骨架，从同一条左边线开始，换页时眼睛不用重新找内容。
- 同一时刻只有真正需要注意的东西显眼，其他都安静。
- 控制台任何一页都能一步回到主页。
- 主页和控制台用同一套颜色，也跟随同一个日间 / 夜间设置。

成功标准：用户在本地试用版里逐页点一遍，觉得比现在整齐，并同意部署。

## 2. 现在的问题（2026-11-03 在 1536×864 下实测）

1. **页面标题的左边有 5 个不同位置**（327 到 494px）。页面宽度有 800 和 1120 两种，又都居中摆放。
2. **提醒信号太多，而且一样响。** 侧栏 11 个状态点，加上页头开关、黄底提示条、标签小圆点、粉色链接，几乎每一行还有一句说明。
3. **样式表里有 12 种字号**（10 到 24px），层级不清楚。
4. **桌面顶栏只是在重复。** 面包屑和侧栏高亮、页面标题说的是同一件事，"小凛在线"一直挂着，换页时也不会变。
5. **每一组设置都包在白卡片里**，卡片外面还有分组标题，概览又是一格一格的卡片，整页看下来全是框。
6. **主页**在宽屏下左侧那条仿 Discord 的侧栏，还在用上一版的粉紫（`#DCC3CD`、`#E7D4DC`），强调色是 `#B0335A`，没有夜间模式。
7. **控制台里没有指向主页的入口**，只有登录页和错误页有。

## 3. 范围

**要改：**
- 控制台外壳：侧栏顶部加回主页的一行；桌面上去掉顶栏。
- 控制台所有页面的排版：概览、11 个模块页、服务器列表、全局设置。
- 主页 `templates/index.html`：换成控制台的颜色，加夜间模式，宽屏侧栏和顶栏同步改色，顺带把"在网页上设置"那块控制台示意图换成新样子。

**保持不变：**
- 后端接口、保存逻辑、草稿和保存条的行为。
- 表单控件的元素 id。各模块脚本只在必须时改动，比如概览改用新的类名。
- 配色 token 的取值。`console.css` 的 `:root` 和夜间色值都不动。
- Ctrl K 搜索、标签页的 `#页面/标签` 深链、服务器切换器、外观切换。
- 登录页和错误页：版面不改，只跟着颜色走。
- 不引入构建工具和框架，文案仍然放在 `website/i18n/zh.json`。

## 4. 排版规则

### 4.1 内容栏

- 内容区**左对齐**，不再居中。左边线永远在侧栏右边的固定距离：宽度 ≥ 1080px 时内边距 `40px 48px`；860 到 1079px 时 `32px`；小于 860px 时 `24px 16px`。
- 普通页面的内容栏最宽 **680px**。概览、服务器列表、全局设置和所有模块页都一样。
- **编辑页**（欢迎新成员、领取身份组）：表单栏 `minmax(0, 680px)`，右边是 320px 宽的预览栏，中间隔 32px。预览栏用 `position: sticky` 固定在顶部 24px。视口小于 1200px 时改成一栏，预览排在表单后面，不再吸顶。
- 去掉 `.page--wide` 和 `.content--page`。编辑页改用 `.page--editor`，最宽 1032px。

### 4.2 页头

- 每个模块页都是：标题（22px、600）、一句介绍（14px、`--muted`），右边是总开关和它的文字（"开启"/"已关闭"）。没有总开关的页面就只有标题和介绍。
- 总开关关着时的提示（`.master-hint`）不再用黄底条，改成介绍下面的一行 13px 文字，颜色用 `--warn`。
- 标签页的标签间距 24px，标签本身左右不留内边距，这样第一个标签和标题对齐。

### 4.3 分组与设置行（平铺列表）

- 分组 `.section` 由三部分组成：标题（16px、600）、一行说明（13px、`--muted`，可以没有）、设置行列表。分组之间隔 32px。
- 设置行列表 `.list` **不要背景、边框、圆角和阴影**，上下各一条 1px 的 `--line` 细线，行与行之间也是一条细线。
- 设置行 `.row`：上下内边距 14px，左右为 0。左边是标题（14px、500）和说明（13px、`--muted`），右边是控件。不可用的行保持现在的变淡效果。
- 其他列表同样平铺：已发送的身份组面板、排行榜、抽奖记录、最近的处罚记录，以及欢迎页里的图卡和外观设置。折叠块（`.fold`）的标题行去掉边框盒，改成一行带箭头的分组标题，展开后的内容按平铺列表排。
- 输入框、下拉框、数字框的底色改用 `--field`，它在夜间模式下和背景能分开。

### 4.4 概览

- 页头：小凛插图缩到 88px，不再放进卡片；标题 22px；下面一行数据（成员、在线、开着几个模块）；右边是"小凛在线"状态（`[data-bot-status]`），这个状态从顶栏挪到这里。
- 需要处理的提示保留黄底，最多 3 条，因为这是真的要去处理的事。
- 模块按三组列出，每组一个分组：标题加一个平铺列表。每个模块一行（`.mod-row`），依次是 36px 的图标块、名字（14px、600）、一句状态（13px、`--muted`，单行，超出部分显示省略号，完整内容放进 `title`），然后是总开关（4 个有总开关的模块）和右箭头（全部模块）。点整行进入模块页，点开关只切换开关。
- 页面底部那句"状态以小凛最近一次上报为准"保留，样式和分组说明一样。

### 4.5 侧栏

- 最上面加一行 `.brand-row`，链接到 `/`：24px 的小凛头像，"小凛 RinBot"（Fredoka 16px），右边是灰色的"⌂ 主页"，`aria-label` 写"回到主页"。服务器列表、全局设置和服务器页都有这一行。
- 侧栏里的状态点：只有 `warn` 状态（模块开着但还没设置好）显示橙点，其他状态（开、关、未知）都不显示。轮询代码不变，只改样式。
- 服务器切换器、Ctrl K 按钮、菜单分组、外观和用户这两行保持不变。

### 4.6 顶栏

- 宽度 ≥ 860px（侧栏常驻时）：**不显示顶栏**。去掉面包屑 `#crumbs`。
- 宽度 < 860px（侧栏变抽屉时）：显示一条 52px 高的顶栏，里面是菜单按钮和当前页面名 `#topbar-title`（`aria-hidden`，在 `show()` 里更新）。
- 无障碍标题：服务器页在内容区最上面放一个 `sr-only` 的 `<h1 id="page-title">`，由 `show()` 更新。服务器列表和全局设置的标题改成页头里看得见的 `<h1>`。原来顶栏右边的"邀请小凛"按钮，挪到服务器列表页头的右边。

### 4.7 保存条

保存条的左边和内容栏的左边线对齐，最宽 680px，编辑页也一样。手机上左右各留 16px。上一轮延后的第 7 项（保存条在宽屏上偏左约 160px）随之解决。

### 4.8 字号

控制台只用五档字号：**12px**（快捷键、小徽标）、**13px**（说明、次要信息）、**14px**（正文、设置行）、**16px**（分组标题、侧栏品牌名）、**22px**（页面标题、概览标题）。

例外：
- 仿 Discord 的消息预览 `.preview-*` 保持 Discord 自己的字号。
- 登录页背后的示意图 `.fake-*` 也保持原样。
- Ctrl K 搜索框 16px。

### 4.9 服务器列表和全局设置

- 服务器列表：页头写"我的服务器"，右边放"邀请小凛"按钮；下面是搜索框，再下面是两个分组（已加入、还没加入）。每台服务器一行（`.server-row`）：40px 的服务器图标、名字，右边是"管理"或"邀请"。原有的 `data-guild-name`、`data-guild-id`、搜索和"没有找到"的行为都不变。
- 全局设置：页头用 `<h1>`，内容按 4.3 平铺。

## 5. 主页

- **token：** `--bg`、`--panel`、`--side`、`--line`、`--text`、`--muted`、`--accent`、`--accent-hover`、`--on-accent`、`--accent-soft`、`--accent-text` 和控制台取值完全一致，日间、夜间两套都一样。原来的 `--rin` 改名 `--accent`，`--chip-*` 改用 `--accent-soft` 和 `--accent-text`。
- **夜间模式：** 和控制台用同一段启动脚本，读 `localStorage['rin-theme']`；`data-theme="dark"` 或系统深色时生效，和控制台的写法一样。主页上不加切换按钮，跟随控制台里的选择，没选过就跟随系统。
- **宽屏侧栏（≥ 1440px）：** 服务器栏用 `--hover`，频道列表用 `--side`，选中的频道用 `--cur` 加 `--shadow-sm`，分隔线用 `--line`。
- **顶栏：** 底色先写 `var(--bg)`，再写 `color-mix(in srgb, var(--bg) 88%, transparent)`。按钮用 `--accent`。
- **Discord 聊天示意：** 日间保持 Discord 浅色主题。夜间换成 Discord 深色主题：背景 `#313338`、深底 `#2B2D31`、分隔线 `#3F4147`、正文 `#DBDEE1`、次要文字 `#B5BAC1`、名字 `#F2F3F5`。
- **光晕和颗粒：** 写死的 `rgba(201, 63, 105, …)` 阴影和光晕，改成基于 `--accent` 的写法；夜间把光晕和颗粒的不透明度减半。
- **控制台示意图**（"在网页上设置"那一节）：改成新控制台的样子，也就是浅灰侧栏、白色选中项和平铺的设置行。
- 主页保留 Fredoka 大标题、小凛贴纸和所有动效，文案不变。

## 6. 测试

现有三套测试全部通过：根目录 `python -m pytest -q`，`website` 下的 `python -m pytest -q tests`，以及 `node --test website/tests/*.test.cjs`。

新增或修改的测试：
- **模板**
  - 控制台基础模板里有 `a.brand-row[href="/"]`。
  - 不再有 `#crumbs`，也不再有 `page--wide`。
  - 概览有 11 个 `.mod-row`，每组都放在 `.list` 里。
  - 服务器列表和全局设置的页头里有 `<h1>`。
  - 服务器页里 `#page-title` 在内容区里，不在顶栏里。
- **样式**
  - `.page` 不居中。
  - `.list` 没有背景。
  - 所有 `font-size` 都在五档以内，只允许 4.8 的例外。
  - 非 `warn` 的状态点不显示。
  - 宽度 ≥ 860px 时不显示 `.topbar`。
- **主页**
  - 第 5 节列出的 11 个 token，日间和夜间都和 `console.css` 的值相同。
  - 有 `rin-theme` 启动脚本，有 `prefers-color-scheme: dark` 的写法。
  - 对比度测试同时覆盖主页。
- **脚本**
  - `show()` 更新 `#topbar-title`，并且没有面包屑时也不出错。
  - 概览的状态行会设置 `title`。
- **视觉检查**
  - 12 个页面和所有标签页，在 1440、1080、375 三个宽度、两种配色下都没有横向溢出。
  - 主页在 1536、800、375 三个宽度、两种配色下都检查一遍。
