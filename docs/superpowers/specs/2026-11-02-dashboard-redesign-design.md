# 控制台改版：Discord 式外壳 + 统一样式

日期：2026-11-02 · 路线图子项目 3（网站改版）的控制台部分 · 状态：待审阅

## 1. 目标

把 `/dashboard`、`/dashboard/server/<id>`、`/dashboard/settings` 三个页面改成和首页同一套视觉，修掉排版错乱，并让常用操作更顺手。读者是正在给自己服务器配置小凛的 Discord 管理员。

完成标准：

- 用户认可新设计。
- 1440 / 1280 / 860 / 375 四种宽度下，所有页面都没有横向滚动；超长的服务器名、频道名、用户名、身份组名不会撑破布局，也不会折成好几行挤掉正文。
- 配色、字体和首页一致；所有文字/底色组合满足 WCAG AA（4.5:1），由测试逐对检查。
- 页面不再依赖 `unpkg` 和 Google 的 Noto Sans SC。
- 所有文案经过一份字典取用，以后加英文只需新增字典，不改布局。
- 现有功能全部保留，后端只做第 7 节列出的三处改动。
- 在本地浏览器里用假数据逐页验证过。

## 2. 改版前的问题（2026-11-02 实测）

在本地用假数据渲染模板，1440 和 375 宽度逐页检查得到：

- 手机上概览（431px）、抽奖（413px）、`pg-personalizer`（431px）横向溢出。原因是管理员名不换行，以及 `server.html` 里写死的 inline 双列 grid。
- 长服务器名重复三次（顶栏、概览卡片、侧栏分组标题）。侧栏标题全大写加字距，英文名折成 3–4 行；手机顶栏标题占 4 行。
- 面包屑写成「我的服务器 / 概览 / 欢迎新成员」，层级不对。
- 概览 6 个统计卡片在宽屏排成 4+2。
- 多个不同区块共用同一个齿轮图标；emoji 和 lucide 图标混用。
- 保存栏一直显示；另有一条浮动的未保存提醒，提示重复。
- 自动审核总开关关闭后，子选项仍可操作；禁言时长要填秒数。
- 指令管理分组默认全折叠，组名是英文 cog 名。
- `pg-personalizer` 已被路由过滤掉，是死代码（全局设置页里有同样的功能）。
- 4 个 CSS 文件互相覆盖（`.mod-banner` 定义了 3 次，手机 media query 写了两份）；`server.html` 有 155 处 inline `style=`。
- `unpkg.com/lucide@latest` 没锁版本，且在 `<head>` 里阻塞渲染；Google Fonts 的 Noto Sans SC 体积大，在中国大陆加载慢或失败。
- 控制台还是旧的米色底加深棕侧栏，和首页的柔和白加粉色侧栏不一致。

## 3. 范围

改动：

- 模板：新增 `templates/_console_base.html`；重写 `dashboard.html`、`server.html`、`settings.html`；`login_gate.html`、`error.html` 只换配色和字体。
- 样式：新增 `static/css/console.css`；删除 `dashboard.css`、`dashboard-ui.css`、`server.css`、`dashboard-extras.css`。
- 图标：新增 `static/icons.svg`（lucide 固定版本中取所需图标，ISC 许可）。
- JS：改造 `dashboard-ui.js`、`dashboard-extras.js`、`message-preview.js`；`server.js` 拆成 `console-core.js` 和 `static/js/modules/*.js`。
- 文案：新增 `website/i18n/zh.json` 和读取它的 `website/i18n.py`。
- 后端：`routes.py` 中第 7 节的三处改动。
- 测试：见第 9 节。

不改动：

- `index.html`（首页）和它的内联 `t(zh, en)` 宏。
- 各模块现有的 GET/POST 接口的请求和返回格式。
- bot 端代码、数据库表结构、两个 `config.py`。

## 4. 设计方向

外壳照 Discord 客户端：最左是服务器图标栏，旁边是功能列表，右边是内容。管理员天天在用 Discord，不用学；首页宽屏侧栏也是这个样子，两边连起来像同一个产品。

内容区照 Discord 服务器设置：一列限宽的设置项，左边说明、右边控件，用细线分组，不把每块都包成卡片；有改动才从底部弹出「有未保存的更改 · 重置 / 保存」。

小凛只在两处露面：概览顶部的值班卡片和空状态。其他页面保持安静。

### 4.1 视觉

颜色沿用首页变量，补上状态色：

| 名称 | 值 | 用途 |
|---|---|---|
| bg | `#F8F6F7` | 内容区底色 |
| panel / line | `#FFFFFF` / `#EDE5E9` | 列表、输入框底色 / 分隔线 |
| text / muted | `#3A2433` / `#6E5565` | 正文 / 说明文字 |
| rin / rin-hover | `#B0335A` / `#962A4C` | 主按钮、开关、当前项强调 |
| chip-bg / chip-text | `#FCE4EB` / `#A3375C` | 次按钮、图标底、选中的分段按钮 |
| rail / chan / active / side-text | `#DCC3CD` / `#E7D4DC` / `#D9C1CB` / `#634A5A` | 服务器栏 / 功能列表 / 当前项 / 侧栏文字 |
| ok / ok-bg | `#276B44` / `#E7F3EC` | 已开启、在线 |
| warn / warn-bg | `#8A5300` / `#FFF4E0` | 没配好、提醒 |
| bad / bad-bg | `#B42318` / `#FDECEA` | 错误、危险操作 |
| bar | `#3A2433`，文字 `#FFFFFF`，「重置」`#F4D6E0` | 未保存提示条 |

字体：

- 标题、数字、品牌名用 Fredoka 500/600，从 Google Fonts 加载，`display=swap`，以 `preload` 方式不阻塞渲染。
- 正文用系统中文字体：`"PingFang SC", "Microsoft YaHei", "Noto Sans CJK SC", system-ui, sans-serif`。
- 字号：24（页面标题）/ 20（数字）/ 16（分组标题）/ 14（正文）/ 12.5（说明）。正文行高 1.6。
- 不用全大写标签，不加字距。

动效：只有三处——未保存提示条滑入、离开时提示条抖动、手机抽屉滑出。不做卡片 hover 浮起。`prefers-reduced-motion` 时全部关闭。

### 4.2 外壳

```
┌──────┬────────────────┬──────────────────────────────────────┐
│ (凛) │ 服务器名…       │ 欢迎新成员                    ● 在线 │
│ ──── │ 概览            ├──────────────────────────────────────┤
│ [超] │ 社区互动        │  设置项（限宽 760px，左对齐）          │
│ (小) │  欢迎新成员   ● │                                      │
│ (G)  │  领取身份组   ● │                                      │
│ (+)  │ 管理与安全      │   ┌──────────────────────────────┐   │
│      │  自动审核     ○ │   │ 有未保存的更改   重置  [保存] │   │
│      │ [头像 用户名]   │   └──────────────────────────────┘   │
└──────┴────────────────┴──────────────────────────────────────┘
  72px      232px
```

- **服务器栏（72px）**：顶部是小凛头像，点了回到 `/dashboard`。下面是分隔线、已加入小凛的可管理服务器（图标或首字），最后是「＋」，跳到 `/dashboard` 的「小凛未加入」区。当前服务器显示圆角方形加左侧指示条；悬停时显示服务器名提示。图标太多时可以单独滚动。在服务器页点别的服务器，跳到 `/dashboard/server/<id>#<当前模块>`。
- **功能列表（232px）**：
  - 顶部显示服务器名，单行，超长截断加 `title`。
  - 「概览」下面分三组，全部展开、不折叠：社区互动（欢迎新成员、领取身份组、等级系统、抽奖）、管理与安全（自动审核、管理模块、机器人运行日志、服务器事件日志）、音乐与工具（音乐、指令管理、通用工具）。
  - 每项右侧有状态点：实心绿表示已开启或已配置，空心表示关闭，黄色表示没配好，灰色表示未知。
  - 底部是用户卡片（头像、名字截断、退出登录）。
- **顶栏**：只有页面名和小凛在线状态。面包屑是「我的服务器 / 模块名」，概览页不显示面包屑。服务器名不再出现在顶栏。
- **`/dashboard`**：服务器栏照常显示，没有选中的服务器。功能列表显示「我的服务器」和「全局设置」，后者只对主人可点，其他人显示「仅主人」。
- **`/dashboard/settings`**：功能列表显示三个分区（小凛资料 / 运行状态 / 全局管理），取代现在的顶部标签。
- **窄于 860px**：服务器栏和功能列表一起收进左侧抽屉，抽屉最宽 `100vw - 48px`；遮罩点击或 `Esc` 关闭，关闭后焦点回到 ☰。顶栏是 ☰ + 页面名 + 在线状态。
- **窄于 1100px**：欢迎和身份组面板编辑页的 Discord 预览从右侧移到表单上方，可以折叠。

### 4.3 设置项与控件

- **设置行**：左边是标题（14/600）和说明（12.5，muted），右边是控件。左栏 `min-width: 0`，文字可以换行；控件不缩小。窄于 860px 时改为上下排列，控件占满整行。
- **区块**：区块标题（16/600）下面是白底列表，行之间用 `line` 分隔。不再给每个区块配图标。
- **依赖关系**：总开关关闭时，同一区块里依赖它的行加 `aria-disabled`，变灰且不能操作，并在说明里写明「先打开上面的开关」。适用于自动审核总开关，以及反刷屏、违禁词、链接过滤、大写、重复这几个子开关；也适用于欢迎、机器人运行日志、服务器事件日志的总开关。
- **时长选择**：分段按钮「1 分钟 / 5 分钟 / 1 小时 / 1 天 / 自定义」。「自定义」展开数字加单位（分钟 / 小时 / 天）。存储仍是秒，取值范围沿用现在的 min/max。读到不在预设里的值时，选中「自定义」并换算显示。
- **下拉框**：沿用 `DashboardExtras.enhanceSelects` 的可搜索下拉；触发按钮单行截断，选项可以换行。
- **按钮**：主按钮（rin 底白字）、次按钮（chip 底）、文字按钮（下划线）、危险按钮（bad-bg 底 bad 字）。按钮文字直接写动作，比如「保存」「发送面板」「建立抽奖」「发送测试日志」。
- **提醒框**：warn 配色，用于身份组位置、权限这类要去 Discord 里检查的事项。
- **焦点**：所有可操作元素显示 2px `#9B3F57` 焦点框。

### 4.4 交互

**保存**

- 有表单的页面（欢迎、自动审核、管理模块、音乐、两种日志）：页面加载完成时记下初始值。值发生变化就从底部滑出提示条，改回初始值后提示条自动收起。
- 「重置」把所有字段恢复为上次保存的值，包括标签列表和勾选的身份组。
- 「保存」时按钮显示加载状态并禁用。成功后提示条收起，弹出「已保存」toast，并刷新状态点。失败时提示条保留，错误原因写在提示条里，输入内容不丢。
- `Ctrl/⌘+S` 等同于点「保存」，只在有改动时生效。
- 有改动时点功能列表、服务器栏或面包屑：不跳转，提示条抖一下并显示「先保存或重置哦」。浏览器关闭或刷新时，仍用 `beforeunload` 提醒。
- 身份组面板和抽奖是「发送 / 建立」型操作，不使用提示条，保留各自的主按钮。表单里有内容时离开同样会被拦下。
- 即时生效的开关（指令开关、概览里的模块开关）：保存期间开关显示加载中并禁用；失败时恢复原状态，并用 toast 写明原因。

**加载与错误**

- 每个模块页第一次打开时，显示和真实布局同形状的骨架占位，加载完成后不跳动。数据只加载一次，切回来不会再次请求，也不会覆盖草稿（沿用 `guardedLoader`）。
- 加载失败的区块显示原因和「重试」按钮。
- 空状态配一张小凛贴纸（WebP，`loading="lazy"`），再加一句下一步操作，例如「还没有抽奖。去 Discord 用 /giveaway 开一场，或者在上面建立一个。」
- 状态轮询保持 30 秒一次，页面隐藏时暂停。数据没变化时不重绘侧栏，焦点不跳。

**键盘**

- `Esc`：依次关闭下拉框、emoji 选择器、抽屉。
- 功能列表和服务器栏都可以用 Tab 走到；当前项带 `aria-current="page"`。

## 5. 页面

### 5.1 服务器列表 `/dashboard`

- 页面标题「我的服务器」，右侧是「邀请小凛」主按钮。
- 搜索框沿用现在的逻辑。
- 「小凛已加入」和「小凛未加入」两组，用自适应网格（`minmax(240px, 1fr)`）。卡片是图标、名字（单行截断加 `title`）和一个按钮。已加入的卡片整张可点，进入设置；未加入的卡片按钮是「邀请小凛」，在新标签页打开。
- 没有可管理的服务器时，显示小凛空状态和邀请按钮。

### 5.2 概览 `#overview`

- **值班卡片**：小凛贴纸（`manage-480.webp`）、「小凛在这里值班 X 了」，加一行数据：成员数 · 在线数 · 文字频道数 · 已开启指令 x/y。数字用 Fredoka。右侧是在线状态。读不到数据的项不显示，不留「—」。
- **模块清单**：分组和功能列表相同。每行是图标、名称、摘要、开关（只有第 7 节第 2 条列出的四个模块有）和「›」；点整行进入设置。
  - 摘要显示这个服务器的实际配置，来自 `/modules` 返回的 `summary`。频道 ID 用缓存的频道列表换算成 `#名字`，超长时截断。
  - 没配好时摘要用 warn 色写明缺什么，比如「还没选日志频道」。
  - 没有 `summary` 时显示模块简介。
- 去掉「其他功能」折叠区和「起步清单」：清单本身已经能看出哪些没配好。

### 5.3 各模块页

每页顶部是页面名和一句话说明（来自字典），没有横幅。

- **欢迎新成员**：
  - 「发送欢迎消息」总开关、欢迎频道、欢迎内文。
  - 「标题和图片」「离开时的道别」「自动给予身份组」三个折叠区，标题后面显示当前状态。
  - Discord 预览：宽屏放右侧并固定，窄屏放表单上方。
  - 图片上传逻辑不变。
- **领取身份组**：面板内文 → 身份组清单 → 发送频道 → 「发送面板」，顺序不变。每一行身份组改成网格（emoji、身份组、删除），手机上不换行；已发送的面板放在页面底部的列表里。
- **自动审核**：总开关和日志频道 → 反刷屏（阈值「几条 / 几秒」、禁言时长选择）→ 违禁词（标签输入）→ 链接白名单（标签输入）→ 其他（大写比例、重复次数）。所有数字框旁边写单位。
- **管理模块**：
  - 日志频道。
  - 「警告自动处罚」用三行表格：处罚（禁言 / 踢出 / 封禁）、警告几次（0 = 不启用），禁言那行多一个时长选择。
  - 最近管理记录：动作用彩色标签（warn / mute / ban / kick / unban…），用户和原因可以换行。
- **抽奖**：表单在宽屏两列、窄屏一列。结束时间提供快捷选项「1 小时 / 1 天 / 1 周 / 自定义」，「自定义」展开 `datetime-local`。下面是抽奖记录列表。
- **等级系统**：排行榜，前三名用奖牌加稍大的字号，名字超长截断，等级和 XP 右对齐。
- **音乐**：DJ 身份组、通知频道。
- **指令管理**：
  - 提示框写「开关立即生效」。
  - 搜索、状态筛选，加上「显示 x / y 条」。
  - 分组默认全部展开，组名映射成中文（字典 `cogs.*`；没有映射的显示原名）。
  - 每组右上角是批量开关，规则沿用：只影响当前筛选结果，跳过必需指令。
- **机器人运行日志 / 服务器事件日志**：日志频道、总开关、等级/分类多选标签、「发送测试日志」次按钮。
- **通用工具**：指令说明列表，自适应网格，手机上单列。
- **删除**：`pg-personalizer` 及其 JS（`loadPersonalizer`、`previewAvatar`、`uploadAvatar`、`changeName`、`savePersonalizer`、`updatePreview`）。全局设置页里的同名功能不受影响。

### 5.4 全局设置 `/dashboard/settings`

套用新外壳，三个分区移到功能列表。内容和现有逻辑不变，只改用新的设置行、按钮和保存方式。小凛资料分区的头像和用户名本来就是各自独立保存的，保留现状，不接入提示条。

## 6. 文案

- 所有界面文案放在 `website/i18n/zh.json`，键按页面和模块分层，例如 `nav.overview`、`welcome.title`、`toast.saved`、`cogs.Music`。
- `website/i18n.py` 读取字典，在 `main.py` 里注册成 Jinja 全局函数 `tr(key, **vars)`。名字不用 `t`，避免和首页的 `t(zh, en)` 宏冲突。
- 模板把当前页面用到的字典以 `<script type="application/json" id="console-strings">` 内联进页面。JS 的 `tr(key, vars)` 读取它；变量写成 `{name}`。缺失的键显示键名，并在控制台警告。
- 布局按英文文案约 1.5 倍长度留余量：按钮和标签不写固定宽度，可以换行或截断。
- 文案风格：动作直接写明；错误写清发生了什么、该怎么办；保留小凛的语气，但不加颜文字。服务器列表页副标题里的颜文字也删掉。

## 7. 后端改动

1. **`/api/guild/<gid>/modules` 增加 `summary`**。在 `_guild_module_config` 读取配置时一并组装摘要。只以只读模式读本地 SQLite（领取身份组和抽奖各多一次计数查询），不额外请求 Discord：
   - welcome：`welcome_channel`、`farewell_channel`、`auto_roles_count`
   - automod：`log_channel`、`rules_on`（五条规则中开启的条数）
   - moderation：`log_channel`、`mute_at`、`kick_at`、`ban_at`
   - music：`notify_channel`、`dj_role`
   - botlog / serverlog：`channel_id`
   - roles：`panels`（这个服务器的面板数）
   - giveaway：`active`（进行中的抽奖数）
   - 其他模块，以及读取失败时：`summary: null`
   
   现有的 `config_state` 不变。
2. **新增 `POST /api/guild/<gid>/modules/<slug>/enabled`**，请求体 `{"enabled": true|false}`。只有 `welcome`、`automod`、`botlog`、`serverlog` 可用，其他返回 404。
   - 权限检查同其他 guild 接口；`enabled` 不是布尔值时返回 400。
   - 执行 `INSERT OR IGNORE` 建行后，只 `UPDATE ... SET enabled=?`，不碰其他列。
   - 调用和该模块保存接口相同的 `_notify_bot`，并写一条 `audit`。
   - 返回 `{"ok": true, "config_state": ...}`。
   - 必须单独加这个接口，因为现有的 POST 接口是整份覆盖：没传的字段会被重置。
3. **`/dashboard/server/<id>` 传入服务器栏数据**。把 `/dashboard` 里「可管理 + 是否已加入」的筛选抽成函数，两个路由共用；服务器页把已加入的可管理服务器（`id`、`name`、`icon_url`）传给模板。`/dashboard/settings` 同样传入。
