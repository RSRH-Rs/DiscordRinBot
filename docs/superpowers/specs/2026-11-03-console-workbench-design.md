# 控制台改版二：工作台布局 + 瓷白樱粉 / 夜幕配色

日期：2026-11-03
前一版：`2026-11-02-dashboard-redesign-design.md`（Discord 式外壳，已上线）
试装实例：`docs/superpowers/specs/assets/2026-11-03-console-workbench-demo.html`（假数据，图片路径来自对比页服务，单独打开时不显示图片）

## 1. 目标

用户反馈上一版"用着不顺手、配色看着不舒服"。这一版要做到：

- 配色干净耐看：九成是白和灰，品牌樱粉只用在能点的和选中的东西上。
- 有夜间模式，默认跟随系统，也可以手动切换。
- 外壳更省地方：去掉服务器竖条，只留一条侧栏。
- 找设置更快：按 Ctrl K 能搜到任意一项设置。
- 概览不再重复侧栏：改成模块卡片，状态和开关一眼看全。
- 长页面不用一直往下滚：欢迎新成员、自动审核两页改用标签页。

成功标准：用户在本地试用版里点一遍，觉得比现在顺手，并同意部署。

## 2. 现在的问题（2026-11-03 实测）

1. 服务器竖条加菜单两条侧栏，一共约 300px，而且是大块中饱和度的粉紫（`#DCC3CD`、`#E7D4DC`），视线总被侧栏抢走。
2. 强调色 `#B0335A` 和背景同一个色相，按钮、开关不显眼；正文黑字 `#3A2433` 也偏紫，整体发灰。
3. 宽屏上内容区只有 760px，概览右侧空出一大片。
4. 概览的模块列表和侧栏菜单一模一样，等于列了两遍。
5. 欢迎新成员、自动审核两页是一长串折叠块和分组，改一个设置要滚很久。

## 3. 范围

**要改：** 全部控制台页面的外壳、配色、排版和组件样式，包括服务器列表、服务器页（概览和 11 个模块页）、全局设置、登录页、错误页。

**保持不变：**
- 后端接口、数据库、保存逻辑：`DashboardUI` 的草稿和保存条、`Console` 的接口调用和缓存、各模块脚本的读写。
- 现有表单控件的元素 id，这样 `static/js/modules/*.js` 基本不用改。
- 文案仍然集中放在 `website/i18n/zh.json`。
- 不引入构建工具、CDN 脚本或前端框架；图标仍然用本地的 `icons.svg`。

## 4. 视觉

### 4.1 配色 token

两套颜色都定义在 `console.css` 的 `:root` 里。白天是默认。夜间有两种生效方式：`html[data-theme="dark"]`，或者系统是深色、用户又没有选白天（`@media (prefers-color-scheme: dark)` 配合 `:root:not([data-theme="light"])`）。

| token | A 瓷白樱粉（白天） | B 夜幕（夜间） | 用途 |
|---|---|---|---|
| `--bg` | `#F7F7F8` | `#17171B` | 页面底色 |
| `--panel` | `#FFFFFF` | `#1F1F24` | 卡片、弹出层 |
| `--side` | `#F0F0F2` | `#121215` | 侧栏 |
| `--line` | `#E4E4E8` | `#2C2C33` | 分隔线、卡片边框 |
| `--field` | `#FFFFFF` | `#17171B` | 输入框底色 |
| `--field-line` | `#8A8A93` | `#6A6A74` | 输入框边框（达到 3:1 非文字对比度） |
| `--text` | `#18181B` | `#EDEDF0` | 正文 |
| `--muted` | `#5F5F68` | `#9A9AA5` | 次要文字 |
| `--accent` | `#D6336C` | `#FF6FA3` | 主按钮、开关、选中项 |
| `--accent-hover` | `#C42A60` | `#FF8DB7` | 主按钮悬停 |
| `--on-accent` | `#FFFFFF` | `#2A0A17` | 强调色上的文字 |
| `--accent-soft` | `#FDECF2` | `#3A1A28` | 标签、选中底色 |
| `--accent-text` | `#B32457` | `#FF8DB7` | 浅强调底色上的文字、链接 |
| `--ok` / `--ok-soft` | `#1A7A43` / `#E7F5EC` | `#3DD68C` / `#13291D` | 正常状态 |
| `--warn` / `--warn-soft` | `#A15C00` / `#FFF4E0` | `#F5B94A` / `#33270F` | 需要处理 |
| `--bad` / `--bad-soft` | `#B42318` / `#FDECEA` | `#FF8A80` / `#3A1715` | 出错 |
| `--cur` | `#FFFFFF` | `#26262C` | 侧栏当前项 |
| `--hover` | `#E7E7EA` | `#1E1E23` | 侧栏悬停 |
| `--bar` / `--bar-text` | `#18181B` / `#FAFAFA` | `#EDEDF0` / `#18181B` | 保存条、提示条 |

用色规则：
- 品牌色只出现在主按钮、开关打开、当前标签下划线、标签和链接上，不做大块底色。
- 绿、黄、红只表示状态，不用来装饰。
- 白天的卡片用很浅的阴影（`0 1px 2px rgba(24,24,27,.06)`），夜间去掉阴影，靠边框区分层次。
- Discord 消息预览在两套配色里都用 Discord 自己的深色（`#313338`），因为它模拟的就是 Discord 里的样子。
- `test_console_contrast.py` 要检查两套配色的每一组文字和底色都达到 4.5:1（WCAG AA）。

### 4.2 字体与排版

- 正文用系统中文字体（PingFang SC / Microsoft YaHei / Noto Sans CJK SC），14px，行高 1.6。
- 字号：页面标题 22px/600，卡片标题 15px/600，设置项标题 14px/600，说明文字 12.5px。
- 只有概览顶部的值班卡片标题用 Fredoka 600（24px），这是全站唯一的展示字体，跟主页保持一致。
- 长名字一律单行截断加省略号，鼠标停留时用 `title` 显示全名；正文和说明允许换行，不截断。

### 4.3 焦点和动效

- 所有能操作的元素都有 2px 的 `--accent` 焦点框（`:focus-visible`），输入框聚焦时外圈加 3px 的 `--accent-soft`。
- 动效只保留三处：保存条滑入、保存条被拦时抖一下、开关切换。系统设置了"减少动态效果"时全部关掉。

## 5. 外壳

```
┌───────────────┬──────────────────────────────────────────────┐
│ [凛] 小凛的家 ⇅│ 概览 › 社区互动 › 欢迎新成员         ● 小凛在线 │
│ ⌕ 搜索设置 Ctrl K├──────────────────────────────────────────────┤
│ ⌂ 概览         │                                              │
│ 社区互动       │                 内容区                        │
│ ☺ 欢迎新成员  ● │                                              │
│ …             │                                              │
│ [头像] Jack ☀▣☾│                                              │
└───────────────┴──────────────────────────────────────────────┘
```

- **侧栏**，252px 宽，`--side` 底色，从上到下依次是：
  1. **服务器切换器**：按钮上显示服务器图标、名字、成员数和 ⇅。点开后是一个弹出层，最上面是搜索框，下面分"小凛已加入"和"还没邀请小凛"两组，组里的数据就是现在各页面已经拿到的 `guilds`；最后两行是"所有服务器"（去 `/dashboard`）和"把小凛加到其他服务器"。没加入小凛的服务器点了会打开 Discord 邀请页，并带上 `guild_id` 预选这个服务器。在 `/dashboard` 页，按钮上显示"选择服务器"。
  2. **搜索设置按钮**：只在服务器页显示，见 6.5。
  3. **菜单**：分组和条目与现在一样，每一项右边有状态点。
  4. **用户行**：头像、名字、外观切换（白天 / 跟随系统 / 夜间三个图标按钮）、退出。
- **顶栏**，56px 高，吸顶，背景半透明加模糊。左边是面包屑（概览 › 分组 › 模块名），右边是小凛的在线状态。
- **内容区宽度**：概览和带预览的模块页最宽 1120px；其他模块页、全局设置、服务器列表最宽 800px；两侧留 32px 边距。
- **手机（≤860px）**：侧栏收成左侧抽屉，顶栏出现菜单按钮，沿用现在的抽屉逻辑。
- 去掉服务器竖条之后，现在 `.rail`、`.rail-item` 相关的样式、模板和 `railClick` 都删除。未保存时的拦截改由切换器里的链接和菜单链接走 `DashboardUI.confirmLeave`。

## 6. 页面

### 6.1 服务器列表 `/dashboard`

结构不变：搜索框，加上"小凛已加入"和"还没邀请"两组卡片。只换新样式，卡片网格按 `minmax(260px, 1fr)` 自动排列。

### 6.2 概览 `#overview`

从上到下：
1. **值班卡片**：小凛插画、"小凛在这里值班 X 了"、成员数、在线人数、已开启功能数（沿用 `overview.js` 里的 `loadInfo`）。
2. **需要处理**：`summaryText` 返回 `warn` 的模块（没选频道、频道已删除等），每个模块一行黄色提示，后面跟一个去处理的链接，最多显示 3 行。没有就不显示。
3. **模块卡片**：按现有三个分组排列，网格 `minmax(230px, 1fr)`。每张卡片显示图标块（模块开着时是 `--accent-soft` 底）、名字、一行摘要（沿用 `summaryText`），右边是快速开关（只有 welcome、automod、botlog、serverlog 四个有）或一个箭头。点卡片进入模块页；快速开关沿用现在的 `POST /modules/<slug>/enabled`。
4. **加载和出错**：数据回来之前，卡片显示骨架占位，快速开关是禁用的；接口失败时整块换成一行出错说明，加一个"重试"按钮。

### 6.3 模块页（通用结构）

- **页头**：标题、一句说明。有总开关的模块（欢迎新成员、自动审核、两个日志），总开关放在页头右边，元素 id 不变（`w-enabled`、`am-enabled` 等），仍然算在这一页的草稿里。
- **设置卡片**：每组设置放在一张卡片里。卡片里每一行左边是标题和说明，右边是控件；文本框、标签列表这类宽控件占满整行。这对应现在的 `row()` 宏，只换样式。
- **依赖关系**：总开关关着时，依赖它的设置行变灰并且不能操作，卡片顶部显示一行"先打开右上角的开关"（补上上一版延后的小问题）。
- **实时预览**：欢迎新成员和领取身份组保留右侧的 Discord 预览，宽 340px，吸顶；1080px 以下移到表单上方。

### 6.4 标签页

只有欢迎新成员和自动审核两页用标签页，其他页面内容不长，保持单页。

| 页面 | 标签 |
|---|---|
| 欢迎新成员 | 欢迎消息 · 图卡与外观 · 道别消息 · 自动身份组 |
| 自动审核 | 规则 · 违禁词 · 链接白名单 |

- 现在的折叠块（`details.fold`）改成标签面板，面板里的元素 id 不变。
- 所有面板一直留在页面里，只是隐藏，所以切换标签不会丢掉没保存的修改，也不会触发离开页面的拦截。
- 地址栏写成 `#slug/tab`（例如 `#welcome/farewell`），刷新后还停在原来的标签。`createHashRouter` 要支持这个后缀：`/` 前面那段仍然是页面 id，只有它变了才算离开页面。
- 有未保存修改的标签，标签名后面显示一个小圆点。

### 6.5 搜索设置（Ctrl K）

- Ctrl K 或 ⌘K 打开一个居中的弹窗，Esc 关闭，方向键选择，回车跳转。
- 搜索的条目直接从页面里收集，不另外维护一份列表：每个 `.page[data-slug]` 的标题、每个标签名、每个 `.row-title` 的文字。条目显示成"模块名 › 设置项"，右边写分组名。
- 选中后跳到对应页面和标签，把那一行滚动到视野里，并闪一下高亮（1 秒）。
- 只在服务器页提供。

### 6.6 全局设置 `/dashboard/settings`

侧栏菜单是"所有服务器"加上现有的三个设置分组（个人资料 / 运行状态 / 管理），不改结构，只换样式。

### 6.7 登录页、错误页

换用新的配色 token，两套配色都生效。登录页模糊背景里的控制台示意图改成新外壳：一条侧栏，概览是卡片网格。

## 7. 外观切换

- `localStorage` 的 `rin-theme` 键可以是 `light`、`dark` 或者没有（跟随系统）。读写都包在 try/catch 里，存储被禁用时就跟随系统。
- `<head>` 里放一小段内联脚本，在页面绘制之前把 `data-theme` 设好，避免先闪一下白色。
- 用户行里的三个按钮用 `aria-pressed` 标出当前选择。

## 8. 文案

新增的文案都放进 `zh.json`，模板和脚本用 `tr()` 读取。包括：切换器（选择服务器、已加入、还没邀请、所有服务器、加到其他服务器、搜索服务器）、搜索设置（按钮、输入框提示、没有结果）、外观（白天、跟随系统、夜间）、概览（需要处理、出错、重试）、标签名、依赖提示。

## 10. 测试与验证
