# 文字、按钮和组件打磨 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让官网和控制台的中文排版、按钮手感、间距和界面切换达到统一的水准，并加五个小组件。

**Architecture:** 官网（`site.css`）和控制台（`console.css`）继续各用一份样式表，只共享令牌名称。控制台的新行为集中在新文件 `static/js/console-controls.js`，挂到现有的 `Console` 对象上。动画全部是 CSS，JS 只负责切换状态。

**Tech Stack:** 原生 HTML/CSS/JS、Jinja2 模板、Node test runner（`vm` + 手写 DOM 桩）、unittest（读样式表做断言）。

**Spec:** `docs/superpowers/specs/2026-11-08-ui-polish-design.md`

## Global Constraints

- 配色和页面结构不动。新增的颜色只有 `--accent-soft-hover` 和 `--bad-soft-hover`。
- `console.css`：字号只能是 `{12, 13, 14, 16, 22}`；间距、圆角、字重沿用 `test_console_contrast.py` 的集合；不用 `!important`。
- `console.css` 用到的每个 `var(--x)` 都要在 `:root` 定义，变量名只能含小写字母和连字符（测试的正则不认数字），只在局部赋值的变量也要给默认值。
- `site.css` 字号只能是 `{12, 14, 15, 16, 18}`；官网页面样式只能是 `{13, 14, 15, 16, 18, 24, 32, 40}`。
- 过渡只列具体属性，禁止 `transition: all`；只动 `transform`、`opacity`，以及第 8 节明确写的高度过渡。
- 令牌：`--ease-out: cubic-bezier(.22, 1, .36, 1)`，`--dur-fast: 120ms`，`--dur-base: 160ms`，`--dur-slow: 200ms`。
- 悬停样式都放在 `@media (hover: hover)` 内。减少动态效果时，所有新动画都要关闭。
- 控制台模块里的文案写进 `website/i18n/zh.json`；`settings.html` 和 `message-preview.js` 已有的内联中文保持内联。
- 375px 宽没有横向滚动，触控目标不小于 44px。
- 提交到本地 master，只 `git add` 本任务的文件，标题用 `feat:/fix:/style:/docs:/test:` 加小写祈使句，不推送。
- 测试命令：根目录 `python -m pytest -q`；`cd website && python -m pytest -q tests`；`cd website && node --test tests/*.cjs`。

## Review Focus

- 确认气泡打开时页面滚动或窗口缩放，气泡不能留在错误的位置，应按取消处理。测试在 Task 4。
- 抽奖在页面打开期间走到 0，文案要变成“等待开奖”，定时器要停；列表重新渲染时不能留下旧定时器。测试在 Task 7。
- 字数里有 emoji，或表单被“重置”按钮改回旧值时，字数环和 `maxlength` 的计数要一致。测试在 Task 5。
- 在隐藏的页面上选中标签时下划线宽度为 0，页面显示后要重新计算。测试在 Task 11。
- 加载中按钮所在的列表被重新渲染，按钮已不在页面上，`Console.busy` 不能抛错或留下定时器。测试在 Task 3。
